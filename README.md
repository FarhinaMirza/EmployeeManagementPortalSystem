# Employee Management Portal System
A centralised Employee Management Portal integrating employee profile, attendance, leave management, payslip, and document management functionalities.

## Overview
The Employee Management Portal is a centralized platform that brings together essential employee-related functionalities in one place. It consists of multiple modules designed to simplify employee self-service, attendance tracking, leave management, payslip access, and document management.

## Modules
### 1. Employee Portal
- Manage employee profiles and personal information.
- View employee-related details.
- Access employee services from a centralized portal.

### 2. Employee Attendance Portal
- View attendance records.
- Track daily attendance and working hours.
- Monitor attendance history.

### 3. Employee Leave Portal
- Apply for leave.
- View leave balances and leave history.
- Track leave request status.

### 4. Employee Payslip Portal
- View monthly payslips.
- Access salary-related information.
- Download payslips, where supported.

### 5. Employee Document Portal
- Upload and manage employee documents.
- Access important employment-related documents.
- Download available documents.

## Key Features
1. Centralized access to employee services.
2. Modular architecture for better maintainability.
3. Simplified employee self-service.
4. Organized attendance, leave, payroll, and document functionalities.
